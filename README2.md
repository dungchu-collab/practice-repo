# About this repo

This is a second readme, added while practicing the basic GitHub workflow:
cloning a repo, creating a file, committing the change, and pushing it up
on a new branch.

## Workflow practiced here

1. Clone the repo
2. Create a new branch
3. Add/edit a file
4. Commit the change
5. Push the branch to GitHub
6. Open a pull request to merge it back into `main`
